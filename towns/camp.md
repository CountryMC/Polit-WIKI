# ⛺ Лагерь

## <mark style="color:$primary;">Команды</mark>

* **`/camp create <название>`** - создать городской лагерь&#x20;
* **`/camp menu`** - меню лагеря
* **`/camp upgrade`** - прокачать уровень лагеря
* **`/camp upgrade <лагерь>`** - прокачать уровень определённого лагеря
* **`/camp menu <название>`** - меню лагеря с определённым названием
* **`/camp delete <название>`** - удалить лагерь
* **`/camp claim`** - заприватить регион лагеря
* **`/camp claim <лагерь>`** - заприватить регион для лагеря с определённым названием
* **`/camp unclaim`** - удалить регион лагеря
* **`/camp unclaim <лагерь>`** - удалить регион лагеря с определённым названием
* **`/camp deposit <число>`** - положить монеты на баланс лагеря
* **`/camp deposit <лагерь> <число>`** - положить монеты на баланс лагеря с определённым названием
* **`/camp invite <ник>`** - пригласить игрока в лагерь
* **`/camp kick <ник>`** - выгнать  игрока из лагеря
* **`/camp leave`** - покинуть лагерь
* **`/camp set spawn <лагерь>`**  - установить точку спавна лагеря
* **`/camp set owner <лагерь> <ник>`**  - сделать игрока новым старейшиной лагеря
* **`/camp remove owner <лагерь>`**  - снять старейшину лагеря с поста

## <mark style="color:$primary;">Использование</mark>

Создать лагерь можно в любом свободном от приватов и других лагерей месте.

* **`/t camp create`** - создать лагерь

Для создания лагеря необходимо собрать следующие ресурсы(дерево может быть любым) и иметь **2 уровень** города.

<figure><img src="../.gitbook/assets/image (8) (1).png" alt=""><figcaption><p>Ресурсы для создания лагеря</p></figcaption></figure>

{% hint style="warning" %}
Лагерь будет существовать **5 дней** с момента создания, после чего будет автоматически удалён!
{% endhint %}

{% hint style="info" %}
Вокруг лагеря можно приватить регионы города(/t claim)
{% endhint %}

Существование лагеря можно продлить используя команды:

* **`/t camp extend <кол-во дней 1-5>`** - продлить существование лагеря на определённое кол-во дней
* **`/t camp extend`** - открыть меню продления лагеря

<figure><img src="../.gitbook/assets/Screenshot from 2023-03-22 18-32-51.png" alt=""><figcaption><p>Отображение лагеря на карте</p></figcaption></figure>

* **`/t camp time`** - остаток времени до удаления лагеря

Лагерь можно удалить не дожидаясь автоматического удаления, но это будет стоить **250⛂:**

* **`/t camp delete`** - удалить лагерь

Для телепорта в лагерь ты должен быть максимально сытым:

* **`/t camp spawn`** - телепортироваться в лагерь

{% hint style="info" %}
После телепорта сытость будет на минимуме.
{% endhint %}
