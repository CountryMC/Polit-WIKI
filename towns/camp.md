# ⛺ Лагерь

## <mark style="color:$primary;">Команды</mark>

* **`/camp create <название>`** - создать городской лагерь&#x20;
* **`/camp menu`** - меню лагеря
* **`/camp upgrade`** - прокачать уровень лагеря
* **`/camp upgrade <лагерь>`** - прокачать уровень определённого лагеря
* **`/camp menu <название>`** - меню лагеря с определённым названием
* **`/camp delete <название>`** - удалить лагерь
* **`/camp claim`** - заприватить регион лагеря
* **`/camp claim gui`** - меню регионов лагеря
* **`/camp claim <лагерь>`** - заприватить регион для лагеря с определённым названием
* **`/camp unclaim`** - удалить регион лагеря
* **`/camp unclaim <лагерь>`** - удалить регион лагеря с определённым названием
* **`/camp deposit <число>`** - положить монеты на баланс лагеря
* **`/camp deposit <лагерь> <число>`** - положить монеты на баланс лагеря с определённым названием
* **`/camp invite <ник>`** - пригласить игрока в лагерь
* **`/camp kick <ник>`** - выгнать  игрока из лагеря
* **`/camp leave`** - покинуть лагерь
* **`/camp set spawn <лагерь>`**  - установить точку спавна лагеря
* **`/camp set owner <лагерь> <ник>`**  - сделать игрока новым старейшиной лагеря
* **`/camp set name <лагерь> <название>`** - переименовать лагерь
* **`/camp remove owner <лагерь>`**  - снять старейшину лагеря с поста

## <mark style="color:$primary;">Использование</mark>

Создать лагерь можно в любом свободном от приватов и других лагерей месте, но в радиусе 4 чанков не должно быть регионов других городов. Для создания лагеря нужны определённые ресурсы в инвентаре города

* **`/camp create <название>`** - создать лагерь

<figure><img src="../.gitbook/assets/image (60).png" alt=""><figcaption><p>Ресурсы для создания лагеря</p></figcaption></figure>

{% hint style="warning" %}
По умолчанию город может иметь только два лагеря. Увеличить их количество можно выбрав определённый [#politicheskii-stroi](politic-system.md#politicheskii-stroi "mention")
{% endhint %}

Лагерь может иметь собственные регионы, жителей и своего старейшину, а также баланс монет.

{% hint style="info" %}
Жителем лагеря может быть абсолютно любой игрок на сервере, но старейшиной может быть только житель города, которому принадлежит лагерь.
{% endhint %}

При создании лагеря по умолчанию в нём нет старейшины. Назначит старейшиной можно только игрока их собственного города:

* **`/camp set owner <лагерь> <ник>`**  - сделать игрока новым старейшиной лагеря

После этого старейшина может распоряжаться приватами регионов и приглашением новых жителей в лагерь:

* **`/camp claim`** - заприватить регион лагеря
* **`/camp invite <ник>`** - пригласить игрока в лагерь
